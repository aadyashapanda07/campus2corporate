# 🎓 Campus2Corporate - AI-Powered Placement Prep Platform

> An all-in-one placement preparation suite designed to bridge the gap between academic learning and corporate expectations.

---

## 🌟 Key Features

- 📊 **Smart Student Dashboard**: Track daily problem streaks, aptitude accuracy rates, mock test performances, and upcoming drive notifications.
- ⏱️ **Timed Aptitude Prep**: Real placement aptitude assessments (Quantitative, Logical, Verbal) modeled after top recruiting companies (TCS, Infosys, Wipro, Accenture).
- 💻 **Interactive Coding Arena**: Built-in code editor supporting Multiple languages (C++, Java, Python, JavaScript), sample test case execution, and placement leaderboards.
- 📄 **AI ATS Resume Analyzer**: Instant ATS scoring, missing keywords breakdown, layout checks, and actionable recommendations.
- 🤖 **AI Mock Interview Terminal**: Realistic technical & HR interview simulations with behavioral scoring and performance feedback.
- 📁 **PDF Resource Sharing Hub**: Community hub to upload, view, share, and download placement roadmaps, cheat sheets, and formula notes.
- 💼 **Placement & Job Portal**: Curated job listings and internship openings with direct application tracking.

---

## 🚀 How to Run Locally

### Option 1: Instant Standalone Preview (Zero Dependencies)
Open `preview.html` directly in any modern web browser:
```bash
# Or serve with Python:
python -m http.server 8080
```
Then visit: `http://localhost:8080/preview.html`

### Option 2: Full React + Vite Development Build
```bash
# 1. Install dependencies
npm install

# 2. Start Vite local dev server
npm run dev
```
